# AzhChat — бриф на редизайн

Документ для дизайнера. Описывает продукт, все экраны, состояния и реальные
ограничения бэкенда. Всё, что здесь написано, **уже работает в коде** — если
не отмечено обратное.

Живой прод: https://azh-chat.netlify.app

---

## 1. Что это за продукт

Веб-мессенджер с групповыми каналами и real-time доставкой сообщений.
Ментальная модель — **Discord/Slack в миниатюре**: пользователь состоит в
нескольких каналах, у каждого канала есть список участников, админ и
инвайт-код, по которому в канал вступают.

Ключевые сущности: **Пользователь → Канал → Участники → Сообщения**.

Личных диалогов 1-на-1 нет. Любое общение — внутри канала.

## 2. Технические рамки (важно при рисовании)

| Что | Значение |
|---|---|
| Тип приложения | SPA (React + Vite), не сайт с перезагрузками |
| Тема | Только тёмная. Светлой темы нет и в задачу не входит (если нужна — это отдельный объём работ) |
| Иконки | `lucide-react` — рисовать в этом стиле (тонкий линейный сет, stroke 2px) |
| Модальные окна | MUI `Modal` — центр экрана, оверлей, фиксированная ширина 400px |
| Адаптив | Брейкпоинт один и главный: `lg` = **1024px**. Ниже него боковые панели превращаются в выезжающие шторки |
| Real-time | Socket.io — сообщения и статусы прилетают без перезагрузки, интерфейс должен уметь показывать «связь потеряна» |
| Шрифт | Сейчас системный, кастомного нет — можно предложить свой |

Разрешения макетов: **1440px (desktop)** и **390px (mobile)** обязательны.
Планшет (768px) — по факту выглядит как мобильная версия.

## 3. Карта экранов

```
/           → Лендинг            (только для НЕзалогиненных)
/auth       → Вход / Регистрация (только для НЕзалогиненных)
/dashboard  → Основное приложение (только для залогиненных)
/*          → любой другой адрес ведёт на /dashboard
```

Логика редиректов: залогиненного с `/` и `/auth` выкидывает на `/dashboard`,
незалогиненного с `/dashboard` — на `/`.

**Отдельной страницы 404 нет** — сейчас любой битый адрес открывает дашборд.
Это можно спроектировать (см. раздел 9).

## 4. Экран 1 — Лендинг (`/`)

Одноэкранная промо-страница. Задача — объяснить за 5 секунд и увести в регистрацию.

Что на нём сейчас:

1. **Шапка** — логотип-текст «AzhChat» слева, кнопка «Login» справа.
2. **Герой** — крупная иконка мессенджера, подзаголовок
   «Create groups and message with friends», одна CTA-кнопка «Start».
   *Заголовка H1 фактически нет — есть только иконка и подзаголовок. Это дыра,
   при редизайне нужен нормальный заголовок.*
3. **Три карточки-фичи** (в ряд на десктопе, в столбик на мобиле):
   - Chat with Friends — «сообщения в реальном времени»
   - Create Groups — «групповые беседы»
   - Share Achievements — «делись успехами»
4. **Футер** — подпись автора.

Что нужно от редизайна: полноценный первый экран (заголовок + подзаголовок +
CTA), возможно скриншот/мокап самого чата, чтобы было видно продукт.

## 5. Экран 2 — Авторизация (`/auth`)

Одна карточка по центру, внутри — **переключатель из двух табов**:
`Sign in` / `Sign up`. Форма меняется, страница — нет.

**Поля «Вход»:** Email, Пароль.
**Поля «Регистрация»:** Email, Nickname, Пароль, Повтор пароля.

Состояния, которые надо отрисовать:

- **Ошибка поля** (под инпутом, красный текст + иконка): «Email is required»,
  «Минимум 3 символа» (ник), «Минимум 6 символов» (пароль), «Пароли не совпадают».
- **Глобальная ошибка** — баннер над формой с иконкой и крестиком-закрытием:
  «Неверный email или пароль», «Пользователь с таким email уже существует»,
  «Ошибка сети».
- **Загрузка** — кнопка со спиннером, все поля задизейблены и приглушены.

Есть кнопка «назад» в левом верхнем углу.

⚠️ Сейчас у страницы **сломана цветовая логика**: блок ошибки светлый
(белый фон, красный текст) на тёмной странице. Нужны тёмные варианты алертов.

Чего в продукте **нет** и рисовать не нужно: восстановление пароля, вход через
Google/GitHub, подтверждение почты, «запомнить меня».

## 6. Экран 3 — Дашборд (`/dashboard`) — 90% продукта

Трёхколоночный лэйаут на десктопе:

```
┌───────────────┬──────────────────────────────┬────────────────┐
│  СЛЕВА        │   ЦЕНТР                      │  СПРАВА        │
│  360px        │   резина                     │  240px         │
│               │                              │                │
│  профиль      │  шапка канала                │  аватар канала │
│  поиск        │  ──────────────────────────  │  название      │
│  2 кнопки     │                              │  описание      │
│  ──────────   │  лента сообщений             │  ────────────  │
│  список       │                              │  участники     │
│  каналов      │  ──────────────────────────  │  (список)      │
│               │  поле ввода                  │  ────────────  │
│               │                              │  удалить канал │
└───────────────┴──────────────────────────────┴────────────────┘
```

На мобиле обе боковые колонки — **шторки поверх контента** с затемнением фона:
левая выезжает слева (кнопка-бургер в шапке), правая — справа (кнопка в шапке
справа). Скролл body при открытой шторке блокируется.

### 6.1 Левая колонка — навигация

Сверху вниз:

- **Блок профиля** — аватар-кружок с первой буквой ника, ник. Кликабелен
  целиком → открывает модалку профиля. Рядом иконка «выход».
- **Поиск** — инпут с иконкой лупы. ⚠️ **Сейчас это муляж, он ничего не ищет.**
  Нужно решить, что он ищет: каналы, сообщения или людей.
- **Две кнопки в ряд**: «Create group» (акцентная, синяя) и «Enter code»
  (вторичная).
- **Заголовок секции** «CHANNELS (n)».
- **Список каналов**. Строка канала = аватар (картинка или кружок-градиент с
  первой буквой) + название + описание в одну строку с обрезкой.
  Состояния строки: обычная / ховер / **активная**.

Состояния списка: `Loading...` / `No channels yet` / `Error loading channels` —
сейчас это просто серый текст по центру, нужны нормальные empty-state'ы.

Чего нет и надо продумать при редизайне: счётчика непрочитанных, превью
последнего сообщения, времени последнего сообщения, сортировки, разделения
на «мои каналы / где я участник».

### 6.2 Центр — чат

**Шапка канала (высота 56px):** иконка `#`, название канала, справа —
инвайт-код в формате `Admin code • ABC123`. При потере соединения рядом с
названием появляется красная пометка `(Disconnected)`.

⚠️ Инвайт-код сейчас видят **все участники, а не только админ**, и он висит в
шапке постоянно. При редизайне логичнее спрятать его в правую панель /
в отдельную кнопку «Пригласить» с копированием в буфер.

**Лента сообщений.** Все сообщения выводятся **одинаково, в одну колонку
слева** — аватар, ник, дата-время, пузырь с текстом.

⚠️ Главная проблема текущего дизайна: **свои сообщения не отличаются от чужих**.
Код автора сообщения вычисляется, но никак не используется. Разделение «мои
справа / чужие слева» (или любой другой визуальный приём) — задача №1 редизайна.

Что ещё стоит спроектировать в ленте, потому что этого нет: группировка
подряд идущих сообщений одного автора, разделители по дням («Сегодня»,
«Вчера»), статус доставки, разделитель непрочитанного.

Пустое состояние ленты: иконка + «No messages yet» + «Be the first to send a message!».

**Поле ввода.** Тёмный блок со скруглением, плейсхолдер `Message #название`,
справа иконка «отправить». Кнопка неактивна, пока поле пустое или пропал
коннект; при обрыве связи весь инпут дизейблится.

Чего нет: вложений, эмодзи-пикера, ответов, редактирования/удаления сообщения,
многострочного ввода. **Бэкенд этого не умеет** — если рисуете, помечайте как
«будущее».

**Индикатор «печатает…»** — особый случай: сервер уже присылает эти события,
на фронте их просто некуда показать. Дизайн этого элемента нужен, реализация
дешёвая.

**Экран без выбранного канала** (первое, что видит новый пользователь):
иконка `#`, «Select a channel to start», «Choose a channel from the sidebar».
Это фактически онбординг — сейчас он пустой и не подсказывает, что делать
дальше (создать группу / ввести код).

### 6.3 Правая колонка — инфо о канале

- Кнопка «редактировать» (карандаш) — **только у админа**.
- Крупный аватар канала (или градиентный кружок с буквой), название, описание.
- Заголовок «MEMBERS — n», рядом «+» для добавления участника — **только у админа**.
- **Список участников**: аватар-кружок с буквой, ник, бейдж `ADMIN` у создателя,
  зелёная точка-статус на аватаре, иконка удаления при ховере —
  **только у админа и только для не-админов**.
- Внизу красная кнопка «Delete channel» — **только у админа**.

⚠️ Зелёная точка «онлайн» сейчас **горит у всех всегда** — статус не приходит.
Нужно нарисовать оба состояния (онлайн/офлайн), даже если данные появятся позже.

## 7. Модальные окна (7 штук)

Все — одного типа: центр экрана, ширина 400px, тёмный фон, затемнённый оверлей,
внизу пара кнопок «отмена / действие».

| Модалка | Откуда | Содержимое | Кто видит |
|---|---|---|---|
| **Профиль** | клик по себе в сайдбаре | аватар, ник, статус «online», Email (только чтение), Nickname (редактируемый), «Save» | все |
| **Создать группу** | кнопка «Create group» | Название, Описание, «Create» | все |
| **Ввести код** | кнопка «Enter code» | одно поле под код, формат `#ABC123` (6 символов, автоматически апперкейс, `#` подставляется сам), «Join» | все |
| **Редактировать группу** | карандаш в правой панели | Название, Описание, «Save» | админ |
| **Добавить участника** | «+» в правой панели | поиск по нику → список найденных (аватар, ник, email) → выбор → «Add Member» | админ |
| **Удалить участника** | иконка у участника | «Точно удалить {ник}?» + подтверждение | админ |
| **Удалить канал** | красная кнопка внизу | «Точно удалить #{канал}? Действие необратимо» | админ |

Внутри модалок нужны состояния: загрузка (текст кнопки меняется на
«Adding…» / «Saving…» / «Deleting…»), «Searching…», «No users found», ошибка.

⚠️ Два бага, которые видно в UI:
1. Модалка «Добавить участника» **не открывается** — она написана, но не
   подключена к экрану. Функционально фича есть, точки входа нет.
2. Ошибки серверных операций показываются **системным `alert()` браузера**.
   Нужен дизайн тостов/нотификаций — это отдельный компонент, которого нет.

## 8. Роли и права

Ролей две, они определяются на уровне канала:

- **Админ** (создатель канала) — редактирует канал, добавляет и удаляет
  участников, удаляет канал.
- **Участник** — только читает и пишет.

Один и тот же человек может быть админом в одном канале и участником в другом,
интерфейс правой панели меняется в зависимости от канала.

⚠️ У обычного участника **нет кнопки «покинуть канал»** — войти может, выйти нет.
Явная дыра, стоит спроектировать.

## 9. Что реально есть в данных (не выдумывать лишнего)

**Пользователь:** id, email, nickname, avatar_url.
**Канал:** id, название, описание, avatar_url, admin_code (6 символов),
creator_id, роль текущего пользователя.
**Сообщение:** id, автор (id + ник), текст, время создания.

Из этого следует:

- Аватарки — поле есть, **но загрузить картинку в интерфейсе сейчас нельзя**.
  Везде фолбэк: цветной градиентный кружок с первой буквой имени. Нужен либо
  дизайн загрузки аватара, либо система генерации цветных заглушек (сейчас
  градиенты захардкожены и повторяются у всех).
- Нет: статусов «прочитано», реакций, тредов, закреплённых сообщений, ролей
  кроме админа, описания профиля, времени последнего входа.

## 10. Все состояния, которые надо нарисовать

Это чек-лист — по опыту, именно их забывают:

- Загрузка списка каналов / профиля / истории сообщений
- Пустой список каналов (новый пользователь)
- Пустая лента сообщений (новый канал)
- Не выбран канал (стартовый экран)
- Ошибка загрузки каналов
- **Потеря соединения с сокетом** — шапка + задизейбленный инпут
- Ошибки валидации форм (инлайн под полем)
- Глобальные ошибки (сейчас `alert`, нужны тосты)
- Загрузка внутри модалок
- Поиск: идёт поиск / ничего не найдено
- Длинные названия каналов, длинные ники, длинные сообщения без пробелов
- Канал на 50+ участников (скролл правой панели)

## 12. Приоритеты редизайна

**Критично (ломает пользование):**
1. Свои vs чужие сообщения в ленте.
2. Система нотификаций/тостов вместо `alert()`.
3. Внятный стартовый экран «канал не выбран» с призывом создать/вступить.
4. Тёмные варианты алертов и ошибок на экране авторизации.

**Важно:**
5. Индикатор «печатает…».
6. Онлайн/офлайн состояния участников.
7. Переосмыслить инвайт-код: сделать кнопку «Пригласить» с копированием
   вместо кода в шапке.
8. Точка входа для «Добавить участника» (модалка уже готова).
9. Кнопка «покинуть канал» для участника.

**Желательно:**
10. Строка канала в сайдбаре: непрочитанные + превью последнего сообщения.
11. Разделители по дням и группировка сообщений в ленте.
12. Загрузка аватаров (профиля и канала).
13. Осмысленный поиск в сайдбаре (решить, что он ищет).
14. Первый экран лендинга.
15. Страница 404.

## 13. Что отдать в результате

- Макеты 1440 и 390 для трёх экранов + всех состояний из раздела 10.
- Все 7 модалок.
- UI-кит: кнопки (основная / вторичная / опасная, все состояния), инпуты
  (обычный / фокус / ошибка / дизейбл), аватар (4 размера + правила заглушек),
  строка канала, строка участника, сообщение, тост, бейдж, пустое состояние.
- Токены цвета и типографики списком — их надо будет один в один перенести в код.
